\# Personal Profile Web Application



\## Description

A simple personal profile website developed

using HTML and CSS.



\## Features

\- Home section

\- About section

\- Education details

\- Skills

\- Projects

\- Contact information



\## Technologies Used

\- HTML

\- CSS

\- Shell Scripting

\- Git

\- Docker

\- GitHub



\## Execution

The application is hosted locally using Docker

on port 8080.
